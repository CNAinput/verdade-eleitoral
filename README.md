# Verdade Eleitoral

Registo dos resultados eleitorais oficiais da CNA. Projeto do INPUT.

Site estático (HTML, CSS e JS), sem build nem dependências.

- Ver localmente: `python -m http.server` na pasta e abrir `http://localhost:8000`.
- Dados: `dados/eleicoes.json` (resultados) e `dados/mandatos.json` (linha de tempo).

Este README é temporário.
